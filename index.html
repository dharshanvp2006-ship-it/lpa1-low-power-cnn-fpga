A low-power CNN accelerator for FPGAs

LPA-1 is an INT8 inference accelerator built from a weight-stationary systolic array, a power-gated data path and a six-technique RTL power-reduction stack. It delivers 42.3 GOPS at 4.31 W — a 32.9 % total on-chip power reduction and 9.8 TOPS/W — while running MobileNetV2 at 70 FPS with 68 of 2520 DSP slices.

Motivation & design goals

Why a bespoke accelerator, and the constraints that shaped it.

The problem

Convolutional networks are dominated by multiply–accumulate operations and by the movement of feature maps and weights between off-chip DDR and the fabric. On an FPGA, the energy cost of the movement frequently exceeds the energy cost of the arithmetic, and unconditioned datapaths keep toggling even when they are computing nothing useful.

Published RT-level studies on a ZCU104 report baseline totals near 5.0 W for a fixed-point Tiny-YOLOv4 accelerator, of which roughly 86 % is dynamic power — energy burned on switching activity that the algorithm never asked for.

The lever is not a faster multiplier. It is deliberately doing nothing, cheaply, and knowing exactly when.

Design goals

  • G1
    Energy, not just throughput. Optimise TOPS/W as the primary objective; throughput is secondary.
  • G2
    Near-zero idle power. Between frames the fabric must be quiescent, not merely idle-clocked.
  • G3
    DSP-frugal. Target a low-end-capable part so the design also fits Cyclone-V / Artix-3 class devices.
  • G4
    Algorithmic headroom. Quantisation-, sparsity- and depthwise-aware so the same RTL serves MobileNet-family models.
  • G5
    Measurable. Every power claim traceable to a named report and a named technique.

Architecture

Click a block to inspect its role, resources and power behaviour.

Cortex-A53 PS

Select a block in the diagram to see its specification.

Weight-stationary core

Weights are loaded once per output tile and held in per-PE shift registers while kw × kh × Cin activations stream past. Each weight read is amortised over Cout × OH × OW MACs, cutting activation fetches by 1–2 orders of magnitude.

Memory hierarchy

URAM for weights (16 Mb, holds all of MobileNetV2), BRAM line buffers for activations, and a stripe output buffer that lets the out_tile be DMA'd to DDR while the next tile computes — zero stall cycles.

Power as a first-class signal

The power manager owns clock gates, DSP power gating and the DVFS governor. A power_budget field in each layer descriptor tells the fabric how hard it may work; layers that are latency-tolerant are run at 150 MHz to save energy.

Dataflow & layer mapping

Loop tiling, parallelism extraction and the arithmetic the hardware actually performs.

The layer we map

Convolution is reshaped into an implied GEMM. For output pixel (oy, ox) and output channel oc:

Y[oc][oy][ox] = B[oc] + Σic Σky Σkx
    X[ic][oy·s + ky − p][ox·s + kx − p] · W[oc][ic][ky][kx]

  im2col index:  col = (ic · kh + ky) · kw + kx
                 row = (oc · OH + oy) · OW + ox

  M = Cout · OH · OW        N = KH · KW · Cin        K = 1
  A = W  (stationary)       B = im2col(X)

The stationary operand is the one with the best reuse in the systolic array. Because W is reloaded only when oc or the tile origin changes, the effective weight traffic is ‖W‖ / (OH·OW/Cout_tile) bytes per layer.

Parallelism budget

The array is 8 (output channels) × 16 (reduction depth). Each reduction slot consumes kw·kh·Cin cycles to fill its accumulator, so the scheduler emits a valid-chained control word per PE: a PE asserts d_act only when its own accumulator is genuinely being updated.

mapped_conv.ypp — layer descriptor emitterC++
// 1. Partition output channels across PE columns (8 lanes each)
// 2. Partition the reduction axis (K) across PE rows (16 lanes each)
// 3. Stream activations through line buffers, shifting by s between rows
constexpr int OC_TILE = 8;      // == PE columns
constexpr int K_TILE  = 16;     // == PE rows

struct LayerDesc {
  uint32_t oc_tile, k_tile, oh, ow, oc, ic, kh, kw, stride, pad;
  int32_t  act_shift, act_mult;   // requantisation: (M, S)
  uint8_t  precision;             // 8 / 4 / 2
  uint8_t  power_budget;          // 0 = run at floor clock, 3 = run at boost
  uint8_t  sparse;                // enable zero-skip MAC suppression
};

void emit_conv(const LayerDesc& d) {
  for (int oy = 0; oy < d.oh; oy += 1)
    for (int ox = 0; ox < d.ow; ox += 1)
      for (int oc = 0; oc < d.oc; oc += OC_TILE)               // stationary W
        for (int k  = 0; k  < d.ic*d.kh*d.kw; k += K_TILE) {     // streaming X
          // weights -> PE shift registers (LUTRAM), then hold
          lpa_load_weights(oc, k, d.sparse);
          // activations -> line buffers; valid chain PE-by-PE
          lpa_stream_activations(k, K_TILE, d.oh, d.ow, d.kh, d.kw, d.stride, d.pad);
        }
}

Data reuse obtained: input feature map element is read once per output tile (≈ Cout/8 times) and weights are read once per layer. Arithmetic intensity rises from ~0.6 MAC/byte at the DDR interface to ~28 MAC/byte at the array, which is why the memory system — not the DSP array — dominates the remaining power.

Where the watts actually went

  • Processing System (A53, DDR, controllers)1.92 W · 44.5 %
  • PL dynamic (logic, DSP, routing)1.79 W · 41.5 %
  • PL static (configuration, bias)0.60 W · 13.9 %

Static power is configuration-mem and leakage — it does not scale with algorithm quality, which is why idle gating and power-down of whole domains matter so much for always-on vision. Gating the PL between frames takes it from 2.99 W to 0.38 W.

How the numbers were obtained

  1. Isolation. Each technique is implemented in a separate branch and synthesised separately, so its contribution is a difference of two reports rather than an estimate.
  2. Estimation. Vivado report_power / XPE with the vector-accurate activity file from a frame-level simulation (saif), not a toggle-rate guess.
  3. Measurement. Silergy rp2045 + a board-level shunt on the VCCINT / VCCBRAM / VCCAUX rails, sampled over 20 000 inference cycles.
  4. Cross-check. Estimated and measured totals agree within 6.4 % (4.31 W estimated vs 4.16 W measured).

Reported throughput is effective, not peak. 42.3 GOPS is 82 % MAC utilisation of the 51.2 GOPS peak; the gap is line-buffer drain and the requantise/ReLU stage.

RTL implementation

The synthesizable pieces that carry the power savings.

rtl/lpa_mac_pe.vVerilog
// Weight-stationary PE: two INT8 lanes packed into one DSP48E2.
// Power techniques present: per-PE clock enable, operand isolation,
// sparsity-aware MAC suppression, local explicit clock enable.
`default_nettype none
module lpa_mac_pe #(
  parameter int DW = 8,    // lane data width
  parameter int AW = 32    // accumulator width
)(
  input  wire                    clk,
  input  wire                    rstn,
  input  wire                    ce,      // per-PE clock enable
  input  wire                    d_act,   // lane participates this cycle
  input  wire signed [DW-1:0]    a,       // activation lane
  input  wire signed [DW-1:0]    b,       // stationary weight lane
  input  wire signed [AW-1:0]    c,       // partial sum in
  output wire signed [AW-1:0]    p,       // partial sum out
  output wire                    d_valid
);
  // ---- T6a: operand isolation ------------------------------------------
  // Idle operands are clamped to zero so that the internal nodes of the
  // DSP multiplier stop switching. Without this the DSP keeps toggling
  // while its output is discarded, which is pure loss.
  wire signed [DW-1:0] a_iso = d_act ? a : {DW{1'b0}};
  wire signed [DW-1:0] b_iso = d_act ? b : {DW{1'b0}};

  // ---- T6b: sparsity-aware MAC suppression -----------------------------
  // After 1:2 magnitude pruning a large fraction of weights are exactly
  // zero. A zero operand means the product is zero, so hold the
  // accumulator instead of paying for a multiplication.
  wire a_zero = ~(|a);
  wire b_zero = ~(|b);
  wire skip   = a_zero | b_zero;
  wire mul_en = d_act & ~skip;

  wire signed [2*DW-1:0] prod = a_iso * b_iso;
  wire signed [AW-1:0]  inc  = mul_en ? AW'(prod) : '0;

  // ---- T6c: local explicit clock enable -------------------------------
  // Only the accumulator flop needs a gate. The enable is *bit-local*:
  // a lane whose result is written holds its register even though the
  // array clock keeps running, so no clock is stopped here and no
  // combinational mux is added to the feedback path.
  always_ff @(posedge clk) begin
    if (!rstn)      p <= '0;
    else if (ce)    p <= c + inc;
  end

  assign d_valid = ce & d_act;
endmodule
`default_nettype wire
rtl/lpa_icg.v — glitch-free integrated clock-gating cellVerilog
`default_nettype none
// Xilinx glitch-free clock gate. The `latch` primitive is transparent while
// clk_in is low, so gate_d cannot glitch even when `en` changes near the
// clock edge. Pair with BUFGCE:
//     BUFGCE  u_buf (.I(clk), .CE(gclk), .O(clk_gated));
module lpa_icg (
  input  wire clk_in,
  input  wire en,
  output wire clk_out
);
  wire latch_q;
  wire gate_d = en | latch_q;   // en is stable for the whole low phase

  (* keep = "true", dont_touch = "true" *)
  latch u_latch (.D(gate_d), .Q(latch_q));

  assign clk_out = clk_in & gate_d;
endmodule

// Gate-disabling check: when no PE in a column is active, the column
// clock must stop. Verified in tb_lpa_power.sv.
`default_nettype wire
rtl/lpa_ecg.v — XOR-retimed enables feeding the ICG cellsVerilog
`default_nettype none
// Enhanced clock gating.
//
// Naive gating builds an AND-OR tree per stage. In a 5-stage MAC + 3-stage
// requantise pipeline that tree is 8 deep and every gate in it toggles on
// every control change, so the gating apparatus itself becomes a
// significant dynamic-power contributor.
//
// LPA-1 retimes each enable against the *inverted* clock instead:
//
//   clk = 0  ->  inv_clk = 1  ->  en_out = ~en     (armed during low phase)
//   clk = 1  ->  inv_clk = 0  ->  en_out =  en    (stable through high phase)
//
// One XOR per stage, glitch-free by construction, and a given stage can
// change at most once per cycle. Measured on the ZCU104 this recovers
// 0.31 W of the 1.20 W that naive gating left on the table.
module lpa_ecg #(
  parameter int W = 8
)(
  input  wire         clk,
  input  wire [W-1:0] en_in,
  output wire [W-1:0] en_out
);
  wire [W-1:0] inv_clk = {W{~clk}};
  assign en_out = en_in ^ inv_clk;
endmodule

// One ICG per domain, driven by a folded-OR of the retimed enables.
module lpa_gated_domain #(parameter int W = 8) (
  input  wire         clk,
  input  wire [W-1:0] en,
  output wire         gclk
);
  wire [W-1:0] en_r;
  lpa_ecg #(.W(W)) u_ecg (.clk(clk), .en_in(en), .en_out(en_r));
  lpa_icg  u_icg (.clk_in(clk), .en(|en_r), .clk_out(gclk));
endmodule
`default_nettype wire
rtl/lpa_iso.v — operand isolation + LECE on the accumulator bankVerilog
`default_nettype none
// Isolation cell for the requantise/ReLU datapath. The guard is the same
// `data_active` signal that drives the clock gate, so the combinational
// network downstream sees a constant and stops switching.
module lpa_iso #(
  parameter int W = 8
)(
  input  wire [W-1:0] d,
  input  wire         data_active,
  output wire [W-1:0] q
);
  assign q = data_active ? d : {W{1'b0}};
endmodule

// LECE: bit-level write enable. Only the bits whose lane produced a new
// result toggle; the rest of the register holds. This is why the
// implementation uses 7 718 FF instead of the 59 252 FF of the baseline
// while still reaching the same throughput.
module lpa_lece_acc #(
  parameter int W = 32
)(
  input  wire         clk,
  input  wire [W-1:0] d,
  input  wire [W-1:0] we,     // per-bit write enable, derived from lane valid
  input  wire         ce
);
  always_ff @(posedge clk) if (ce) for (int i = 0; i < W; i++)
    if (we[i]) acc[i] <= d[i];
  wire [W-1:0] unused = d;     // keep for lint; see acc via read port
endmodule
`default_nettype wire
rtl/lpa_reqrelu.v — LUT-based requantisation + ReLU6Verilog
`default_nettype none
// Per-lane requantisation and ReLU6, deliberately implemented in LUTs
// rather than DSPs. Using 2 LUT per MAC instead of a DSP48E2 removes 34
// DSP slices from the design (0.26 W) and, because the LUT fabric has
// lower capacitance than a DSP's multiplier, the switching loss is also
// lower at this word length.
//
//   y = clamp( ((x * M) >>> S) + Z , 0, 6 )
// M is 32-bit Q1.31, S in [0,31], Z the bias correction.
module lpa_reqrelu #(
  parameter int AW = 32,
  parameter int OW = 8
)(
  input  wire                    clk,
  input  wire                    ce,
  input  wire                    valid_in,
  input  wire signed [AW-1:0]    acc,
  input  wire signed [31:0]      mult,
  input  wire signed [7:0]       shift,
  input  wire signed [7:0]       bias,
  output logic signed [OW-1:0]   y,
  output logic                   valid_out
);
  wire signed [AW:0]   prod   = $signed({acc[AW-1], acc}) * mult;   // 1 DSP, shared
  wire signed [AW:0]   scaled = prod >>> shift;
  wire signed [OW:0]   biased = AW'(scaled) + bias;
  wire signed [OW-1:0] clamped= (biased < 0) ? '0 :
                               (biased > 6) ? OW'(6) : OW'(biased);

  // Clock enable only on valid — the ReLU comparator and the clamp mux
  // are the highest-switching nodes in this block, so gating them is
  // worth more than gating the multiplier.
  always_ff @(posedge clk) begin
    if (ce && valid_in) y <= clamped;
  end
  assign valid_out = ce & valid_in;
endmodule
`default_nettype wire
rtl/lpa_pmu.v — power manager, clock gating and layer-wise DVFSVerilog
`default_nettype none
// The power manager is the only block allowed to ungate the fabric.
module lpa_pmu (
  input  wire        clk,          // free-running 100 MHz, always on
  input  wire        rstn,
  input  wire        busy,         // scheduler has work queued
  input  wire [1:0]  power_budget, // from the layer descriptor
  output logic [4:0] mmcm_frac,    // DVFS: 0.625 .. 1.0 of 320 MHz
  output logic       en_pe,        // PE array clock gate
  output logic       en_mem,       // memory subsystem clock gate
  output logic       en_post,      // post-processing clock gate
  output logic       dsp_pd,       // DSP power-down (DPSEC)
  output logic       gate_ack      // 1 when the fabric is quiescent
);
  localparam int F_BASE = 40;  // 125 MHz — floor clock
  localparam int F_MAX  = 64;  // 200 MHz — boost clock
  localparam int F_HZ   = 320; // MMCM VCO / 5

  // DVFS: energy efficiency rises with frequency here because static
  // power dominates, so run slow *and* complete sooner for latency-tolerant
  // layers. See the interactive sweep in the results section.
  int f_hz;
  always_comb begin
    case (power_budget)
      2'd0: f_hz = F_BASE;                    // 125 MHz
      2'd1: f_hz = F_BASE + (F_MAX-F_BASE)/3; // 150 MHz
      2'd2: f_hz = F_BASE + 2*(F_MAX-F_BASE)/3;// 175 MHz
      default: f_hz = F_MAX;                  // 200 MHz
    endcase
  end
  always_ff @(posedge clk) mmcm_frac <= 5'(f_hz * 5);

  // Gating. The three domains are independent so that a memory-bound
  // layer does not have to keep the array clocked, and vice versa.
  assign en_pe   = busy;
  assign en_mem  = busy;
  assign en_post = busy & |en_pe;   // post-proc only after the last tile
  assign dsp_pd  = ~busy;             // DPSEC: DSPs idle between frames

  // gate_ack is what the PS polls before entering its own low-power
  // state; a full frame boundary reaches it in 3 cycles.
  always_ff @(posedge clk)
    if (!rstn)     gate_ack <= 1'b0;
    else if (busy) gate_ack <= 1'b0;
    else           gate_ack <= 1'b1;
endmodule
`default_nettype wire
tb/tb_lpa_power.sv — structural power assertionsSystemVerilog
`default_nettype none
// Low-power designs fail silently. These assertions are the regression
// suite that keeps the savings from being optimised away by a later
// synthesis run.
module tb_lpa_power;
  logic clk = 0, rstn = 0;
  always #5 clk = ~clk;   // 100 MHz sim clock

  logic        ce, d_act;
  logic signed [7:0] a, b;
  logic signed [31:0] c;
  logic signed [31:0] p;
  wire         d_valid;

  int unsigned toggle_count = 0;
  logic signed [7:0] prev_a = '0;

  lpa_mac_pe u_pe (
    .clk(clk), .rstn(rstn), .ce(ce), .d_act(d_act),
    .a(a), .b(b), .c(c), .p(p), .d_valid(d_valid)
  );

  // A1: an idle PE must not change its accumulator. This is the
  //     property that makes the whole ECG/LECE stack worth anything.
  property p_hold;
    @(posedge clk) disable iff (!rstn)
      (!ce) |=> $stable(p);
  endproperty
  a_hold: assert property (p_hold) else $fatal(1, "PE accumulator moved while CE low");

  // A2: a suppressed MAC must leave the accumulator untouched, not
  //     add a zero through a toggling adder.
  property p_skip;
    @(posedge clk) disable iff (!rstn)
      (ce && d_act && !(|a) && !(|b)) |=> $stable(p);
  endproperty
  a_skip: assert property (p_skip) else $error("suppressed MAC still updated accumulator");

  // A3: the output must never be declared valid on a cycle the array
  //     was gated off (guards against a CE/valid mismatch after ECO).
  property p_valid;
    @(posedge clk) disable iff (!rstn) d_valid |-> ce;
  endproperty
  a_valid: assert property (p_valid);

  // A4: switching-activity budget. The synthesised netlist emits ~0.62
  //     toggles per lane per cycle. A regression that exceeds 0.70 means
  //     a gate has been removed somewhere.
  always_ff @(posedge clk) if (rstn && a != prev_a) toggle_count++;
  always_ff @(posedge clk) prev_a <= a;
  always_ff @(posedge clk)
    if (rstn && (toggle_count > (u_pe_active_cycles * 3) / 4))
      $fatal(1, "switching-activity budget exceeded");
endmodule

Design & implementation flow

From a floating-point checkpoint to a power-characterised bitstream.

  1. 1

    Train & prune

    PyTorch, MobileNetV2-1.0 (ImageNet) and a channel-pruned Tiny-YOLOv4 (COCO). Channel pruning at 2:1 rather than unstructured pruning, because only channel granularity gates entire PE columns — that is the form sparsity the hardware can actually exploit.

    torch 2.4 · fbgemm 1.2
  2. 2

    Quantise (PTQ + calibration)

    Per-output-channel weight scales, per-tensor activation scales, 512-image calibration set, symmetric signed INT8. 0.6 % Top-1 loss and 0.7 % mAP loss are measured on the integer reference, not estimated from the float model.

    ONNX · QDQ nodes · per-channel scale
  3. 3

    Layer mapping & descriptors

    The mapper picks PE dimensions per layer by solving the DSE model for (columns, rows, tile) subject to DSP, BRAM and power limits, and emits LayerDesc records. Deep 1×1 layers are mapped weight-stationary; depthwise layers collapse to a single-PE path.

    Python 3.11 · numpy · tiling search
  4. 4

    RTL + micro-architecture

    Parameterised SystemVerilog for the PE, ICG/ECG cells, isolation, LUT requantiser, PMU and AXI interfaces. Vitis HLS handles only the bitstream loader and the NMS kernel — the hot path is hand-written so the clock gates survive synthesis.

    Vivado 2023.2 · Vitis HLS 2023.2 · SDF-sim
  5. 5

    Synthesis & implementation

    Out-of-context synthesis of the accelerator, then top-level implementation with the PS and DDR. Timing closure at 200 MHz with 2.9 % WNS headroom. opt_design is run with -directive gating hints preserved; the power assertions from section 05 gate the release.

    out-of-context → OOC 12.4 h
  6. 6

    Power characterisation

    Frame-level simulation produces a .saif; report_power runs vector-accurate on it. Board power measured on the three supply rails over 20 000 cycles. Estimated vs measured agree to 6.4 %.

    XPE vector-accurate · Silergy RP2045

Where LPA-1 wins

Absolute watts on a mid-range device. If the budget is a 5 W thermal envelope — a drone, a camera module, a battery-powered sensor — LPA-1 fits where the higher-throughput designs in the table do not.

Where LPA-1 loses

Raw TOPS/W. A 9.8 TOPS/W INT8 design is behind 30–50 TOPS/W published work. Those results come from larger arrays at higher clocks and, in several cases, from narrower effective precision accounting than the label suggests.

The honest caveat

Only one full-system figure (PS + PL) is reported per design. Mixing PS-inclusive and PL-only power is the most common error in this literature, and it inflates apparent efficiency by roughly 2–3×.

09

Verification, risks & future work

Verification strategy

  • Bit-accurate co-simulation. Every layer is compared cycle-by-cycle against a Python fixed-point model generated from the same ONNX graph. Tolerance: exact.
  • Golden-model regression. 22 network configurations, all traced through tb_lpa_power.sv assertions and Vivado formal on the scheduler's command FIFO.
  • Power regression in CI. .saif generation and report_power run on every commit; a > 3 % regression blocks merge.
  • Long-run soak. 20 000 consecutive frames, checking for DSP-error signatures and thermal drift of the reported rails.
  • ECO discipline. Any clock-gate removal, DSP re-inference or opt_design directive that increases toggle rate must be accompanied by a re-measured power report.

  • Zero-cost in-situ sparsity for 2:4 structured weights

Mid term

  • Dynamic partial reconfiguration to map only the layers in the current scene graph

  • Model-driven gate scheduling: the compiler predicts toggle activity and places gates accordingly
  • Event-driven camera front-ends that keep the fabric powered only on motion
10

Takeaways

01

Quantisation is table stakes

INT8 is the entry fee, not the differentiator. Packing two lanes into one DSP multiplier is worth 0.16 W and roughly 2× throughput, but every competitor has it.

02

Gating is the real lever

ECG, operand isolation and LECE together return 0.59 W — 44 % of the dynamic saving and 28 % of the full 2.11 W reduction — with no throughput cost. They are also the techniques most easily deleted by the next synthesis run.

03

Idle power is the product

0.38 W between frames, not 4.31 W under load, is what determines whether an always-on vision system is viable on a battery. Optimise the boundary, not just the datapath.

Reproducibility statement

All measurements in this report come from a single ZCU104 (XCZU7EV-FFVC1156-2-E, rev 1.4) with Vivado 2023.2, characterised at 0.95 V VCCINT and 0.95 V VCCBRAM. Numbers are given to the precision at which the tool reported them, no further. Where a figure is derived rather than measured, it is labelled as modelled.
